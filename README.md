# Agenda EF v2
PWA escolar para organizar tareas, calendario, materias, materiales, calificaciones y horario.

Sube estos archivos al repositorio de GitHub Pages reemplazando los anteriores. Conserva la carpeta `icons`.

Esta versión guarda los datos localmente y permite exportar/importar un respaldo. La sincronización automática entre dispositivos se añadirá con un backend/base de datos en una siguiente etapa.
